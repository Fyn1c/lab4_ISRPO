# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

# Общее описание решение
в каждом файле представлены 2 функции возвращающие периметр и площадь в зависимости от фигуры
# Описание функций
## circle.py
```python
def area(r)
```
функция считает и возвращает площадь круга 
на вход принимает радиус круга
пример: 
```python
area(5) = 78,5
```

```python
def perimeter(r)
```
функция считает и возвращает периметр круга
на вход принимает радиус круга
пример:

```python
perimeter(5) = 31,4
``` 

## rectangle.py
```python
def area(a,b)
```
функция считает и возвращает площадь прямоугольника 
на вход принимает 2 стороны прямоугольника
пример: 
```python
area(5, 4) = 20
```
```python
def perimeter(a,b)
``` 
функция считает и возвращает периметр прямоугольника
на вход принимает 2 стороны прямоугольника
пример:

```python
perimeter(5, 10) = 30
``` 
## square.py
```python
def area(a)
```
функция считает и возвращает площадь квадрата 
на вход принимает сторону квадрата
пример: 
```python
area(5) = 25
```

```python
def perimeter(a)
``` 
функция считает и возвращает периметр квадрата
на вход принимает сторону квадрата
пример:

```python
perimeter(5) = 20
``` 
## triangle.py
```python
def area(a,h)
```
функция считает и возвращает площадь треугольника
на вход принимает сторону треугольника и высоту, проведённую к этой стороне
пример: 
```python
area(5, 4) = 10
```

```python
def perimeter(a,b,c)
``` 
функция считает и возвращает периметр треугольника
на вход принимает 3 стороны треугольника
пример:

```python
perimeter(5, 4, 3) = 12
```
